# 🎂 Birthday Gift Processing Department™ (Web App)

A hilarious, over-engineered corporate bureaucracy birthday gift selector for a friend whose birthday is tomorrow.

Built with **React 18**, **Tailwind CSS**, **Canvas Confetti**, and **Web Audio API** synthesized sound effects.

## 🚀 How to Open and Run

Because this app uses browser-native technologies and CDNs, it requires **zero installation**, **zero npm dependencies**, and **zero builds**.

### Option 1: Local Server (Recommended)
Run the included PowerShell server which automatically opens your default browser:
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
Or simply open:
👉 **[http://localhost:3000/](http://localhost:3000/)** (while the server is running)

### Option 2: Direct in Browser (Offline / Double-Click)
Double-click or open [index.html](file:///c:/Users/garim/.gemini/antigravity-ide/scratch/birthday-gift-selector/index.html) directly in any web browser (Chrome, Edge, Safari, Firefox). The React application is bundled inline for zero-CORS offline execution!

## ✨ Features & Flow

1. **Screen 1 — Welcome**:
   - Official heading & commemorative protocol tag.
   - Clickable ✏️ inline name editor to personalize `[NAME]` for your friend on the fly!
   - Satirical text deeming them "worthy" of receiving a present.
   - Satisfying "ENTER GIFT PORTAL →" transition.

2. **Screen 2 — Requisition Catalogue (5 Gift Cards)**:
   - 🍺 **The Druk Package**: 2 × Druk Beer Cans (*"For hydration purposes, obviously."*)
   - 💪 **The Gains Package**: 500g Plant Protein (*"Because apparently muscles are important."*)
   - 💆 **The Premium Package**: 1 × Shoulder Massage (*"Handcrafted. Limited edition. Appointment subject to availability."*)
   - 🧸 **The Soft Package**: One Plushie (*"No explanation necessary. You deserve a little guy."*)
   - ❓ **The Mystery Gift**: Suspicious pulsing hazard card with *"RISK IT"*.

3. **Bureaucratic Confirmation Modals**:
   - **Standard Gift**: *"Are you sure? Once submitted, your choice enters the Birthday Gift Processing Department™."*
   - **Mystery Gift**: *"⚠️ WARNING: You are about to surrender control of your birthday gift... [YES, GIVE ME THE MYSTERY] / [I WANT BEER]"*

4. **Screen 3 — The Processing Department**:
   - Multi-stage animated progress bar with authentic corporate messages updating every ~700ms:
     1. *"Submitting request..."*
     2. *"Contacting Birthday Gift Department™..."*
     3. *"Checking inventory..."*
     4. *"Obtaining management approval..."*
     5. *"Approving unnecessary paperwork..."*
     6. *"Gift approved."*

5. **Screen 4 — Gift Approved**:
   - Multi-burst celebratory canvas confetti!
   - Official Certificate Card with rotated green rubber stamp (`Status: APPROVED ✓`).
   - Unique generated Reference Number (`BDAY-[4 digits]`).
   - Simulated barcode and dispatch metadata.
   - Closing sentiment: *"Thank you for being born. ❤️"*
   - "START OVER" and "COPY DISPATCH RECORD" buttons.

6. **Easter Eggs & Delights**:
   - Web Audio synthesizer sound effects (pops, clicks, stamps, celebration fanfare) with an audio toggle.
   - "Terms of Gifting" corporate bylaws modal in top navbar.
   - Fully responsive for mobile and desktop.
